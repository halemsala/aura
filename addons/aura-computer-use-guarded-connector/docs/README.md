# aura-computer-use-guarded-connector

Addon isolado de **governança** para futura integração com Hermes Computer Use / cua-driver.

## Estado desta instalação
- computer_use_enabled=false
- execution_allowed=false
- network_allowed=false
- approval_required=true
- driver externo: não instalado
- serviços: nenhum

## Não faz
Mouse, teclado, navegador, microfone, câmera, gateway, scheduler, autostart, YOLO.

## Ativação
Segunda implantação separada, com aprovação explícita, allowlist, timeout, limite de ações, logs e botão de parada. Primeiro teste apenas em janela fictícia (Notepad/Calculadora).
