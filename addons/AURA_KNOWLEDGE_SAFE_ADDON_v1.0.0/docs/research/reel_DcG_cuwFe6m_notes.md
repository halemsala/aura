## Conhecimento extraído
A postagem descreve o Find Skills como uma Skill da Vercel para descoberta automática de Skills para Claude Code. O usuário descreve a tarefa em linguagem natural; o buscador consulta um diretório amplo, filtra resultados por instalação real, popularidade no GitHub e fonte confiável e instala o resultado diretamente no Claude Code por um comando.

## Limitações
O nome e o link do repositório não aparecem no HTML público acessível. A contagem de “mais de 700 mil Skills” é uma alegação da legenda e não foi validada independentemente. O vídeo em si e seu áudio não ficaram disponíveis como arquivo público no acesso sem login; portanto, não é possível afirmar se há instruções adicionais, demonstração de terminal ou nomes de comandos além da legenda.
