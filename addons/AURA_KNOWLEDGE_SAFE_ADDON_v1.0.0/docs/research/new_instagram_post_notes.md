## Quadros 1 e 2 confirmados visualmente

Quadro 1: “6 SKILLS ESTUPIDAMENTE ÚTEIS que todo usuário de Claude deveria instalar agora.” Rodapé: “Comente SKILLS para receber todas prontas.” A arte usa ícones de dúvida, régua, lupa, cursor, medidor e carimbo “EVIDÊNCIA”, sugerindo planejamento, medição, investigação, interação e verificação.

Quadro 2: “O Claude é inteligente. Mas ainda tem vícios estúpidos.” A ilustração mostra uma interface, um bug e um botão “PRONTO”, sugerindo dois problemas: criação de interfaces com qualidade inconsistente e conclusão prematura sem validação.

## Conteúdo da legenda já extraído

A legenda afirma que o Claude começa sem entender direito, cria interface com aparência genérica de IA, tenta corrigir bugs por tentativa e erro e diz que terminou sem testar. Apresenta seis Skills:

1. Grill Me: transforma ideias vagas em planos claros.
2. Frontend Design: combate o “AI slop” em interfaces.
3. Systematic Debugging: encontra a causa real dos erros.
4. Webapp Testing: abre o navegador e testa o aplicativo.
5. Web Quality Audit: verifica performance, SEO, mobile e acessibilidade.
6. Verification Before Completion: impede o Claude de declarar conclusão sem apresentar provas.

A legenda também afirma que não é necessária outra coleção de prompts aleatórios, mas um setup que ensine o Claude a trabalhar melhor em todas as etapas. Convite final: comentar “SKILLS” para receber o guia completo com links, comandos e explicações.

## Quadros 3 e 4 confirmados visualmente

Quadro 3: apresenta uma interface de site com texto “Design que move, engaja e converte”, estratégia, crescimento e coleção. Texto principal: “Se o seu Claude ainda cria site genérico, instala isso.” Chamada: “Comenta DESIGN.” Este quadro ilustra a função da Skill Frontend Design: produzir interfaces menos genéricas, com direção visual, hierarquia, propósito e elementos de conversão.

Quadro 4: “O único plugin que sua IA precisa” e, em destaque, “Setup Agent”. Chamada: “Comenta SETUP que te mando o link.” Trata-se de uma chamada promocional; o quadro não fornece especificação técnica suficiente para afirmar qual plugin, API ou implementação está por trás do termo Setup Agent.

E outro procura a bomba antes de você publicar.” O fluxo visual é “PLAN → CODE → TEST → REVIEW → SECURITY”. Chamada: “Comenta AGENTE pra receber tudo na sua DM.”
