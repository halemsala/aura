# AURA Explanation Skill

Toda explicação deve distinguir dados observados, cálculo determinístico, avaliação advisory e recomendação. Mostre `source_ids`, versão das Skills, qualidade, frescor, confiança e motivo de qualquer bloqueio. Use `N/D` quando uma informação não estiver disponível.

Não apresente uma sugestão advisory como ordem, aposta, garantia ou fato confirmado. Não omita limitações relevantes para deixar a resposta mais persuasiva.
